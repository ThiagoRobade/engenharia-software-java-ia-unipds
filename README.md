# engenharia-software-java-ia-unipds
Repositório de estudos e projetos da Pós-Graduação em Engenharia de Software com Java e IA (UNIPDS). Aborda Java moderno, Spring Boot, Quarkus, IA aplicada (LangChain4j, RAG, MCP e Agents), Clean Architecture, mensageria (Kafka/RabbitMQ), mensageria, bancos SQL/NoSQL, Docker, Kubernetes e AWS.
